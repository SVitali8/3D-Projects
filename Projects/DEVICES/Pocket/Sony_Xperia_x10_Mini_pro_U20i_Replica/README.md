
# Sony Xperia X10 Mini Pro (U20i) Replica

Реплика смартфона Sony Ericsson Xperia X10 mini pro (U20i) — 3D-печатный проект с возможностью печати корпусов, моддинга. Включает версии V1 (базовая) и V2 (улучшенная топология, оптимизированные файлы).

Модели подходят для 3D-печати на Creality-принтерах, с корпусом, в версии V1 для экрана 2.55" TFT, версии V2 для экрана 2,8", клавиатурой и слотами под компоненты (Qualcomm MSM7227).

##Цель проекта

Создать, отладить хотя бы минимальные условия для быстрого воспроизведения различных коммуникаторов, для дальнейшего перевоспроизведения, воспроизведения, совершенствования, уменьшения порога вхождения в цифровой мир. За основу взят коммуникатор/мобильное устройство, по тому как понравилась простота использования этого устройства, поэтому очень стоящая модель для миниального повторения форм фактора.


## Версии проекта
 
- V1 Начальная модель: базовый корпус, slide-механизм.
- V2 - Оптимизированная: меньше граней


## Компоненты (Hardware)

- Экран: 2.55" TFT 320x240.
- Процессор/Плата: На основе различных
- Другие: UART/SPI для флешинга, кастом ROM.

Референсы: [Sony U20i specs](https://en.wikipedia.org/wiki/Sony_Ericsson_Xperia_X10_mini_pro).
